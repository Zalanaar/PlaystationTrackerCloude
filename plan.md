## Риски
| Риск | Влияние | Митигация |
|---|---|---|
| PSN API неофициальный, может сломаться или нарушать ToS | Синк перестаёт работать | Фаза 0, изоляция в `src/server/psn/`, показ сохранённых данных |
| NPSSO протухает (около 2 мес.) | Синк молча встаёт | Индикатор на сайте, инструкция обновления |
| Приватность целевого аккаунта | Пустые данные | Проверка в Фазе 0, нужен друг-статус и открытые трофеи/игры |
| Нет истории часов до первого синка | Статистика за прошлое неполная | Снимки с первого дня, пометка в UI. Для прошлых лет Wrapped опирается на трофеи |
| «Пройдено» PSN не знает | Данные зависят от ручной разметки | Статусы ставит Артём, при импорте всё «без статуса» |
| Лимит времени функции Vercel (Hobby) | Синк 169+ игр не успевает | Батчи, продолжение между запусками |
| Cron на Hobby только раз в сутки | Нет частого синка | Достаточно по решению, плюс кнопка «Синк сейчас» |
| Жанров может не быть в PSN | Нет жанровой статистики | Ручные теги или отказ от жанров в MVP |
