# Спека UI: Фаза 13, экран «Подскажи» (`/recommend`, что играть из бэклога)

Статус: черновик designer. Правки 2026-10-29 (решения Артёма, контракт §18.9): до 9 карточек, скрытие на 30 дней, блок «Скрытые на сейчас» (п.3, 6.1, 8.1, 8.3, 11, 12, 14). Фаза 13b (контракт §19): режим «Новое от ИИ» описан в п.15, п.0 для него частично снят (см. вступление п.15). Без новых токенов. Дополняет `docs/design-system.md` (§1, §4.1, §6), не заменяет его. По этому экрану при расхождении прав этот файл. Формат и общие правила как в `spec-phase-12-roadmap.md` (токены вместо hex, `--on-scrim`/`--on-cover-*`, скелеты, `prefers-reduced-motion`, `prefers-contrast: more`, зоны 44, `.num`).
Данные и поведение сервера: `docs/api-contract.md` §18 (при расхождении прав контракт). Тексты только RU. Темы: Night, Graphite, PS1 (светлая), PS2–PS5, один набор токенов.

## 0. Принципы и запреты
- **Выбирает игры детерминированный скоринг, LLM только перефразирует** (§18, решение Артёма). UI это не скрывает: источник фразы виден, но тихо (п.5.4). Никаких «ИИ посоветовал», «умный подбор», аватаров бота, чата.
- Только бэклог (`backlog`). Игр вне библиотеки нет, настроения нет, запрос только по времени.
- **Новых токенов нет.** Всё из существующих (п.1). Новых цветов нет; ошибки и лимиты без `--danger`.
- Фигуры △○□✕ ‖ ◇ только для статусов. Здесь допустима одна: `StatusGlyph backlog` (пустое состояние «бэклог пуст»). Запрещено: `play` (треугольник это △ «играю») на кнопке «Начать играть», крестик для «Не интересно» (это ✕ «брошено»), точки-индикаторы, кружки-ранги. Иконки: `thumbs-down`, `lightbulb`, `chevron-down`, `clock`, `info`, `circle-alert`, `refresh`, `check` (п.2.2).
- Текст не лежит на обложках и баннерах. Название, числа, причина только на `--surface`. На медиа нет ни чипов, ни подписей (читаемость на обложках: §6 системы не затрагивается).
- Цвет не единственный признак: вклад сигнала = знак (+/−) + число + полоска.
- Любая ошибка (сеть, 503, LLM) не роняет экран: показывается последнее, что есть, или спокойное сообщение.

## 5. Причина, источник и сигналы
### 5.1 Причина
`reason.text` целиком, без кавычек и подписей «ИИ». Текст приходит готовым с сервера, UI его не правит.
### 5.2 Раскрывашка «Почему эта игра»
| Элемент | Спека |
|---|---|
| Кнопка-заголовок | во всю ширину, высота 36 (моб. 44), граница сверху `--border`, слева `chevron-down` 14 `--text-2` (поворот 180° при раскрытии, `--dur-base`) + текст 13/18 600 `--text-2` «Почему эта игра»; справа small `--text-3` источник фразы (п.5.4). `aria-expanded`, `aria-controls`. По умолчанию свёрнута. После перезапроса (смена времени, действие) снова свёрнута |
| Содержимое | `<ul>` в блоке `--surface-2`, `--r-sm`, padding 12, анимация высоты `--dur-base` (reduced-motion: сразу) |
| Строка сигнала | grid `minmax(0,1fr) auto`, gap 4 12, padding 6 0, между строками `--border`: слева `label` 13/18 `--text-2` (до 2 строк); справа `num` 13/16 600 `--text` со знаком: «+2,4», «−1,0», «0» (минус U+2212, запятая); под ними на всю ширину полоска высотой 4 `--surface-3`, `--r-pill` |
| Полоска | заливка слева направо шириной `|contribution| / max|contribution|` по карточке (минимум 4% при ненулевом): положительный вклад `--accent`, отрицательный `--text-3`. Вклад 0: пустая полоска. Знак и число дублируют цвет. `role="presentation"` |
| Порядок | как отдал API (вклад по убыванию, штрафы последними); сортировка на клиенте не меняется |
| Итог | последняя строка small `--text-3`: «Итоговый балл: {score}» (`num`, 1 знак) |
| Пустой `signals` | раскрывашка не рендерится (причина остаётся) |
### 5.3 Подписи сигналов
Приходят в `label` (RU, готовые). Клиент их не переводит и не сокращает. Ключи `key` используются только как `data-signal` и для стабильных React-ключей.
### 5.4 Источник причины: ненавязчиво
| `reason.source` | Что видно | Пояснение (`title` / в раскрытом виде) |
|---|---|---|
| `template` | в строке раскрывашки справа small `--text-3` «шаблон» | «Фраза собрана по шаблону из расчёта» |
| `llm` | там же small `--text-3` «ИИ-формулировка» | «Игру выбрал расчёт по твоей истории, ИИ только переписал фразу» |
Правила: на самой причине пометки нет, цвета и иконки нет; пояснение в `title` на правом тексте и первой строкой внутри раскрытого списка small `--text-3` с `info` 12. Для `template` ничего дополнительного (это норма, не «запасной режим»). Слова «ошибка», «лимит» на карточке не пишутся.

## 6. Действия
Ряд внизу карточки: `display: flex; gap 8`. Десктоп: «Начать играть» `flex: 1 1 auto`, «Не интересно» по содержимому. Высота `--control-h` (моб. `--tap-min`). Вертикальной карточки в 3 колонки на 1024 хватает (≈ 304 px внутри); если не помещаются в одну строку, «Не интересно» уходит на вторую строку на всю ширину (`flex-wrap: wrap`, `min-width: 120px` у кнопок).
| Кнопка | Вид | Действие |
|---|---|---|
| «Начать играть» | `.ps-btn--primary`, без иконки, 14/500 | `PUT /api/games/{id}/status` `{"status":"playing"}` (раздел 9, §18.6) |
| «Не интересно» | `.ps-btn--ghost`, `thumbs-down` 16 + текст | `POST /api/recommend/dislike` `{gameId}` (§18.5) |
`aria-label`: «Начать играть: {название}», «Не интересно: {название}».
### 6.1 Состояния кнопок и карточки
| Состояние | Вид |
|---|---|
| hover/focus/active | как в системе (`--shadow-focus`, фон `--surface-3` у ghost) |
| pending (запрос в полёте) | обе кнопки карточки `disabled`; нажатая показывает спиннер 14 и «Запускаю…» / «Скрываю…»; карточка остаётся на месте, `aria-busy`. Прочие карточки активны |
| Успех «Начать играть» | тост ««{название}» теперь в «Играю»» + ссылка-кнопка «К коллекции» (`/`), 6 с. Отмены нет (возврат в бэклог сбросил бы дату ожидания, пользуется окном игры) |
| Успех «Не интересно» | тост «Скрыто на 30 дней: «{название}»» (срок из `ttlDays`, склонение дней) + «Отменить» (8 с): `DELETE /api/recommend/dislike/{gameId}`, затем перезапрос. У кнопки `title` «Скрыто на 30 дней» |
| После обоих | перезапрос `GET /api/recommend` с текущим `time` (§18.6), п.7.3 |
| Ошибка действия | карточка возвращается в обычное состояние, тост (не `--danger`-заливка, обычный тост с иконкой `circle-alert`): «Не удалось начать игру. Повтори» / «Не удалось скрыть игру. Повтори» + «Повторить» |
| `404 not_found` | тост «Игры уже нет в библиотеке», перезапрос списка |
| Идемпотентность | повторное нажатие невозможно (disabled); повтор после обрыва безопасен (оба вызова идемпотентны) |

## 7. Выбор времени
### 7.1 Контрол
`.ps-seg`, `role="radiogroup"` `aria-label="Сколько времени есть"`, 4 сегмента `role="radio"` `aria-checked`. Значения: `any`, `short`, `medium`, `long`.
| Сегмент | Подпись 13/16 600 | Подсказка 11/14 |
|---|---|---|
| `any` | Любое | без ограничения |
| `short` | Короткая | до 8 ч |
| `medium` | Средняя | 8–30 ч |
| `long` | Долгая | более 30 ч |
Подсказки совпадают с окнами §18.3 (≤ 8, 8..30, > 30). Подсказка 11px допустима как micro; цвет `--text-3` в неактивном сегменте, `--text-2` в активном (на `--surface-3`).
| Параметр | Десктоп | Моб. |
|---|---|---|
| Раскладка | сегменты по содержимому, высота 44 (две строки), в строке под h1 | 4 равных сегмента на всю ширину, высота 52, подсказка скрыта на <420 (остаётся подпись), `aria-label` содержит подсказку |
| Клавиатура | roving tabindex: Tab входит в выбранный, стрелки влево/вправо выбирают и применяют, Home/End | то же |
| PS5 | активный сегмент белая pill с `--accent-ink` (как `.ps-chip[aria-pressed]`, декор уже есть) | то же |
Подсказка под контролом (small `--text-3`, одна строка): при `any` «Подбираю по жанрам и истории»; при остальных «Окно считается по оценке времени прохождения». Нет смысла делать длиннее.
### 7.2 Состояние в URL
`/recommend?time=short`. `any` в URL не пишется. Неизвестное значение трактуется как `any` и в URL заменяется (на сервер невалидное не отправляется; `400 invalid_request` по `time` не должен показываться пользователю). Смена сегмента: `router.replace`, без нового шага истории.
### 7.3 Загрузка и смена
| Ситуация | Вид |
|---|---|
| Первая загрузка | скелеты карточек (п.8.1), контрол реальный и доступен |
| Смена времени / перезапрос после действия | текущие карточки остаются без затемнения; в строке подсказки справа спиннер 14 + small `--text-3` «Подбираю…», `aria-busy` на списке. ## 10. Поведение на темах
Один набор токенов, никаких тематических веток в компонентах. Декор подхватывается через хуки `.ps-app`, `.ps-panel`, `.ps-seg`/`.ps-chip`.
| Тема | Поведение |
|---|---|
| Night | обычные поверхности; акцент `--accent` = `#b99cff` (`--cover-tint` здесь не применяется: tint только hero и окно игры); фоновое свечение из декора под контентом |
| Graphite | без декора; акцент и кнопки серые, primary читается по `--accent-ink` (контраст 7+) |
| PS1 | светлая: размытое фоновое медиа (`brightness(.7)`) остаётся тёмным, поэтому плейсхолдер буквы и текст на нём не используются; фаска `.ps-panel` из декора; полоска сигнала `--accent` (тёмный) на `--surface-3` различима; отрицательная `--text-3` + знак «−» |
| PS2 | `.ps-panel` с фаской и туманом позади; ограничение декора по контрасту уже в системе |
| PS3 | волна в верхних 240px, карточки ниже; `--text-3` в строках источника проверяется «с декором» (4.62) |

8. Нигде на экране нет △ и ✕ (в т.ч. как иконок кнопок); из фигур только `StatusGlyph backlog` в пустом состоянии.
9. Мобильная раскладка без горизонтального скролла на 1280, 1024, 768, 360, 320.

## 15. Фаза 13b: режимы «Из бэклога» / «Новое от ИИ» (контракт §19)
Разделы 0-14 описывают режим «Из бэклога» и не меняются. Новые токены не нужны, иконки только существующие: `plus`, `check`, `thumbs-down`, `undo`, `refresh`, `calendar`, `external-link`, `info`, `circle-alert`, `chevron-down`, `lightbulb`. Правила п.0 действуют и здесь (текст не на медиа, фигуры △○□✕ запрещены, `--danger` не используется, цвет не единственный признак).
**Снятые ограничения п.0 только для режима «Новое от ИИ»:** игры вне библиотеки здесь есть; слово «ИИ» допустимо в названии режима и в подписи источника (п.15.3). Список из 9 пунктов и общий принцип «LLM только перефразирует» относятся к режиму бэклога; тут источник идей модель, существование игры подтверждает RAWG (§19, принципы защиты).

### 15.11 Критерии приёмки 13b
1. Переключатель режимов; `?mode=discover` открывает режим, по умолчанию бэклог, невалидное значение сбрасывается; `time` виден только в бэклоге.
2. `GET /api/recommend/discover` не вызывается в режиме бэклога; `refresh=1` только по кнопке.
3. Карточка: обложка RAWG, название, дата выхода, PS-платформы, причина, подпись «Подобрано ИИ, данные RAWG» со ссылкой на rawg.io; текста на обложке нет.
4. «В план» → `POST /api/roadmap/planned`, затем «Уже в плане»; `planned: true` и `409` дают то же состояние без ошибки. «Не интересно» + «Отменить» работают; блок «Скрытые на сейчас» со своим списком.
5. «Обновить подборку · осталось N»; при 0 и при `limit` кнопка выключена с пояснением.
6. Долгая загрузка: текст-этап и полоска, не голый спиннер; результат из кэша без мигания панели.
7. Описаны и сверстаны: пусто (два варианта), `llm: disabled`, `catalog: unavailable`, `limit` (с картами и без), `error` (с картами и без), 503, сеть/таймаут, устаревший кэш; без секретов и имён переменных в тексте.
8. Нет hex/`rgba`, нет △ и ✕, `--danger` не используется, 7 тем читаемы, контраст проходит.
9. Мобильная раскладка без горизонтального скролла на 1280, 1024, 768, 360, 320.
