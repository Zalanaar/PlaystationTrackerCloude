## 0. Общие правила для всех спек
- Никаких hex и `rgba` цветов в компонентах: только токены. Темы: Night (по умолчанию), Graphite, PS1 (единственная светлая), PS2, PS3, PS4, PS5. Имена токенов одинаковы, меняются значения.
- PS1 светлая: `--on-cover-bg/-text/-border` там светлые (чип на обложке светлый с тёмным текстом), `--plat-text` тёмный. Поэтому:
  - Текст и иконки внутри чипов поверх обложки: только `--on-cover-text` на `--on-cover-bg`.
  - Текст прямо на затемнённом арте/скриме (название в шапке окна, слайды Итогов): только `--on-scrim` (новый токен, всегда белый, §1). Скрим `--cover-scrim` тёмный во всех темах.
  - На поверхностях (`--bg`, `--surface*`): `--text*`, акцент `--accent`.
- Не вводить новых hex: производные через `color-mix` от токенов темы.
- Состояния в каждой спеке: загрузка (скелет `.ps-skeleton`, `aria-busy`), пусто, ошибка, нет данных. Ошибка отдельного блока не роняет страницу.
- `prefers-reduced-motion`: без анимаций появления, без shimmer. `prefers-contrast: more`: декор-подложки (wash, glow) скрыты, обводки 2px.
- Мобильная: <768. Зоны нажатия не меньше 44 (`--tap-min`), визуально кнопка может быть меньше, зона увеличивается псевдоэлементом.
- Числа `.num` (tabular-nums). Формат часов/дат: design-system §1.2. Процент редкости: `formatRate` (запятая, 1 знак, `<0,1%`).

## 5. «Убрать из этого месяца» в «Играх месяца» (п.4)

### 5.3 Как показывать исключённые
- Из сетки месяца игра пропадает. Счётчики `MonthHeader` и `BlockHead` считают только оставшиеся.
- Под сеткой месяца, если исключённых игр ≥ 1, строка-кнопка `.ps-st-excl` (высота 36, моб. 44, margin-top 8): иконка `calendar-x` 14 `--text-3`, текст small `--text-2` «Убрано из месяца: 2», справа `chevron-down` 14 (`aria-expanded`, поворот 180° за `--dur-base`). Свёрнута по умолчанию, состояние не сохраняется.
- Раскрыто: плотная сетка тех же `GameCard` (`data-excluded="true"`), анимация высоты `--dur-base`.
  - Обложка: `opacity: .55; filter: grayscale(.5)`. Платиновые элементы (уголок, обводка) тоже приглушены вместе с обложкой.

## 12. Цвет акцента из обложки «Играю» (`--tint`, п.11)
**Область: только Night.** В остальных темах акцент фиксирован (Graphite, PS1–PS5 игнорируют tint), чтобы PS1 (светлая) и тематические декоры не ломались. Реализация: frontend ставит `--cover-tint` (не `--tint`) inline; в `themes.css` Night: `--tint: var(--cover-tint, #b99cff)` (одна строка, правит designer тем). До этого правки: frontend ставит `--tint` inline только при `data-theme` отсутствует/`night` (константа `THEME_USES_TINT`).
### 12.1 Откуда цвет
Доминантный цвет берётся на сервере при синке (CORS CDN PSN не позволяет читать пиксели в браузере): `GameItem.tintColor: string | null` (`#rrggbb`). Нет значения = фолбэк на акцент темы. Клиентской выборки пикселей нет.
### 12.2 Нормализация `safeTint(hex)` (чистая функция, Vitest)
1. В HSL. Если насыщенность < 0.15 (серый) или значение не hex: `null` (фолбэк).
2. `S` зажать в [0.45, 0.85]. `L` зажать в [0.70, 0.82].
3. Проверить: контраст `--accent-ink` (#14101f у Night) на получившемся цвете >= 7:1 и контраст цвета на `--surface-2` >= 4.5:1. Не прошло: повышать `L` шагом 0.02 до 0.88. Всё ещё не прошло: `null`.
4. `null` = атрибут не ставится, работает акцент темы (`#b99cff`).
### 12.3 Где применяется (область действия через локальный `--cover-tint`, не на весь `.ps-app`)
| Элемент | Применение |
|---|---|
| Hero «Играю» (`.ps-hero__main`) | inline `--cover-tint` игры hero: свечение `box-shadow: var(--shadow-card), var(--tint-glow)` (на hover `--shadow-hover` + то же); фигура △ в метке (`--st-playing` = `--accent`); на мобильном hero прогресс-полоса `--accent` на `--surface-3`. Текст hero остаётся белым на скриме (`--on-scrim`) и не зависит от tint. Десктопная полоса hero белая (как §4.4), чтобы не терять контраст на тёмном скриме |
| Мини-карточки `.ps-hero__mini` | у каждой свой `--cover-tint` (своей игры): бар трофеев `--accent`, hover-контур `color-mix(in srgb, var(--tint) 40%, var(--border))` |
| Окно игры `.ps-gd` | `--cover-tint` игры: подчёркивание активной вкладки, бар трофеев в плитке, primary-кнопки, фокус-кольцо **не меняется** (`--focus`), фолбэк-фон шапки без обложки (п.2.2) |
| Не применяется | шапка и навигация, чипы статуса, сетка карточек, Статистика, Итоги, декоративное свечение страницы (остаётся тема-tint). Страничный акцент от «Играю» **не** включаем (опция, нужна отдельная приёмка: он перекрашивал бы всю навигацию при каждой смене игры) |
### 12.4 Ограничения контраста
- Результат `safeTint` по конструкции не ниже 4.5:1 на `--surface-2` и `--bg`, 7:1 с `--accent-ink`.
- Свечение декоративно: не несёт информации, `prefers-contrast: more` и `reduced-motion` его убирают (без `--tint-glow`).
- Статусная фигура △ (`--st-playing`) на `--on-cover-bg` в hero ≥ 3:1 (проверяется на tint-границах L=0.70).
- Бары на `--surface-3` ≥ 3:1 (нетекстовый элемент).
- Тесты: `safeTint` на наборе красный/синий/жёлтый/серый/чёрный/белый/невалидный; результат ≥ контрастов выше.
