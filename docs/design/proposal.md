## 3. Спеки (дополнения к design-system.md)
Шапка: логотип `PS TRACKER` (display 13px, .14em), вкладки, индикатор синка, селект тем (3), аватар. Под ней `h1` + строка итогов (14px, `--text-2`, числа `--text` 600, разделитель `·`).
| Элемент | Спека |
|---|---|
| Хроника: заголовок года | `h2` display 28/32 + «○ пройдено N», «✕ брошено N», «M ч в этих играх»; снизу линия `--border`. Текущий год раскрыт, остальные свёрнуты (шеврон «Развернуть») |
| Месяц | `h3` 13/600 `--text-2` + мини-итоги «○2 ✕1» (фигуры 12px) |
| Сортировка внутри месяца | по дате завершения, новые первыми |
| Игры без даты завершения | группа «Без даты» в конце года, определённого по `last_played_at`; если и его нет, блок «Без даты» после всех годов |
| Блок «Бэклог» | до 5 обложек + плитка «+N ещё в бэклоге»; «Все →» ведёт на вкладку Бэклог |
| Блок «Не разобрано» | плотный режим, кнопка primary «Разобрать по одной» |
| Фигура статуса на обложке | круг 26px (плотно 20), фон `--on-cover-bg`, обводка `rgba(255,255,255,.12)`, фигура 16px цветом статуса, `aria-label`. Без статуса: пунктирная обводка |
| Часы под названием | small, `--text-3`; в списке и на hover: часы, запуски, трофеи с прогрессом |
| Hover (≥1024) | подъём -3px + оверлей `--cover-scrim` с названием, часами, запусками, трофеями; touch: оверлея нет, тап открывает игру, долгий тап 500 мс открывает sheet статуса |
| Фигура `shelved` | две вертикальные черты (пауза), как в текущей системе |
| Статусная иконка в чипах фильтра | фигура + счётчик; на мобильном без подписей, скролл |
| Контраст | текст на обложке только внутри `--on-cover-bg` (бейдж, плашка, оверлей со scrim .88→0); название на `--bg`. Цветной текст статусов не используется (цвет у фигур) |

Разбор (`/triage`): один экран на игру. Очередь = игры без статуса, порядок «по запуску» (по умолчанию) или «по часам».
| Элемент | Спека |
|---|---|
| Верх | `37 / 214`, прогресс 4px, «осталось 177», выход Esc |
| Десктоп | 3 колонки: обложка 340 (3:4) / название display 30, факты (часы, запуски, трофеи, последний запуск), 5 строк-кнопок 52px: `[клавиша] фигура подпись` / очередь «Дальше» 5 миниатюр |
| Клавиши | `1` △ Играю, `2` ○ Пройдено, `3` □ Бэклог, `4` ✕ Брошено, `5` ‖ Отложено, `0` пропустить, `Z` отменить, `←` назад, `Esc` выйти |
| Даты | при 2 и 4 дата = последний запуск (правило 1.3), правка ссылкой «Изменить» |
| Мобильный | стопка карточек, свайп вправо ○, влево ✕, вверх □, вниз пропуск; штамп статуса при перетаскивании; снизу 5 кнопок 56px (Играю и Отложено только на кнопках) и «Пропустить / Отменить» |
| Завершение | экран «Всё разобрано»: итог по статусам и ссылка в Коллекцию |
| API | без изменений: `GET /api/games?status=none&sort=...`, `PUT /api/games/{id}/status`; отмена = PUT с прежним статусом (`null`) |

Статистика и Итоги: используют те же `YearHeader` (заголовок года/периода с итогами) и `GameGrid` (ряды обложек, режим «Плотно»). Статистика: KPI-ряд крупными числами в display, панели `--surface` 82%, график часов (штриховка месяцев до первого синка и плашка-пометка), жанры барами. Итоги: слайд 9:16 с размытой обложкой, 72px числами в display, фигуры △○□✕ как мотив (слайд «Пройдено и брошено»: ○ + число + ряд обложек, ✕ + число + ряд обложек с `saturate(.5)`).
Мобильная версия: контейнер 16px, tab bar 56 (активная вкладка: линия 3px `--accent` сверху иконки), чипы статуса в скролле, поиск 40px, сетка «Крупно» 2 / «Плотно» 3 колонки, ряды по месяцам, sheet статуса 48px строки.
Состояния (загрузка, пусто, ошибка синка, протухший NPSSO): без изменений по логике; скелет карточки = обложка 3:4 + 1 строка; пусто «Не разобрано» = «Всё разобрано» с ссылкой.

## 5. Вопросы к Артёму
1. Шрифт заголовков: Unbounded (широкий, консольный) или Oswald (узкий, плакатный)?
2. «410 ч» в заголовке года: это полные часы игр, завершённых в этом году (не часы, наигранные за год). Так оставляем или считать иначе (в Статистике часы по снимкам)?
3. Пройденные/брошенные игры без даты завершения: группа «Без даты» внизу года. Ок?
4. «Бэклог» есть блоком на Коллекции и отдельной вкладкой (Фаза 4). Оставить оба (блок = превью на 5 игр)?
5. «Отложено» отдельным блоком или внутри «Бэклога»?
6. Цвет акцента из обложки: считать при синке на сервере и хранить (нужно поле в БД, работа backend), или на клиенте через canvas (нужен CORS у обложек PSN, может не работать)? Пока в макете цвет задан руками, запасной `#b99cff`.
7. Прошлые годы свёрнуты по умолчанию. Ок, или развернуть последние 2 года?
8. Порядок блоков: Играю → Хроника → Бэклог → Отложено → Не разобрано. Не поднять ли «Не разобрано» выше, пока таких 177+?
9. Свайп в Разборе: вправо ○, влево ✕, вверх □, вниз пропуск. Подходит?
10. Платина осталась маленьким значком на обложке (единственный трофейный элемент в сетке). Оставляем?
