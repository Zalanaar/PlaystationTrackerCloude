# Предложение: темы PS1–PS5 (Фаза 14, шаг 1)

Статус: макет на выбор Артёма. `src/` и `docs/design-system.md` не тронуты, токены переносятся после выбора.
Макет: `docs/design/mockups/themes-ps.html` (открыть в браузере, без сборки; шрифты с Google Fonts). Верхняя панель: переключатель 6 тем (`data-theme`), «Все 6 рядом», вариант PS1 «цвета кнопок», эмуляция reduced motion. Ниже 3 телефона 390px (PS1, PS3, PS5, тему каждого можно сменить) и живая таблица контраста выбранной темы (считает WCAG по вычисленным CSS-переменным).
Разметка одна (`<template>` клонируется), тема = значения токенов + 2–4 декоративных правила.

## 3. Activity: слить с PS5
Решение: слить, `activity` → `ps5`.
- Совпадают 4 из 5 признаков: чёрный фон, белый акцент, размытый арт «Играю» фоном, белый контур активного. Отдельно остались бы только радиусы. Две почти одинаковые темы в меню из 7 пунктов: выбор без разницы.
- PS5 забирает механизм `--page-art` и платину Activity без изменений, добавляет pill-навигацию и activity-карточки.
- Заодно лечится контраст Activity (§4): затемнение фона сильнее.
- Миграция: сохранённое `ps-theme=activity` → `ps5` (как в §7 п.2 design-system сброс старых имён), `THEMES` в `index.ts`: Night, Graphite, PS1–PS5 (7 пунктов).

**Найденные проблемы (существующие темы)**
- Activity сейчас: `--text-3` на фоне с очень светлым артом (белая обложка, opacity .34, затемнение .35) ≈ 3.2. Исправлено в PS5 (.28 / .45 → 4.97).
- Night: в пике свечения `--tint` под шапкой `--text-3` ≈ 4.5 (на грани). Там им набраны только точки-разделители в StatLine. Не трогал (вне задачи), при желании свечение 20% → 16%.
- PS1 в варианте «цвета кнопок»: красный ○ «Пройдено» совпадает по цвету с `--danger` (ошибка синка). Различаются фигурой и подписью, но ассоциация «красное = ошибка» остаётся. Поэтому вариант по умолчанию «спокойный».
- PS2: первый кандидат акцента #7fa8ff почти совпадал с `--st-service` #78b4ff (△ и ◇ одного цвета), заменён на #cfe0ff.

## 5. Риски декора
| Тема | Производительность | Мобильный (<768) | `prefers-reduced-motion` |
|---|---|---|---|
| PS1 | статичный градиент, дёшево | без изменений | анимаций нет |
| PS2 | 1 слой с `transform`, без `filter` | дрейф выключен, слой статичный | `animation: none`, туман статичный |
| PS3 | слой 200% ширины × 300, только `transform` | волна статичная, `top: 260px`, высота 200 | `animation: none`, волна статичная |
| PS4 | слой 100vh + 240 с частицами, `transform`; в проде `position: fixed` (не на всю длину страницы, иначе огромный слой на 214 играх) | частицы скрыты | `animation: none` |
| PS5 | `blur(64px)` на полноэкранном слое и `backdrop-filter` на карточках: самое дорогое | `backdrop-filter` выключен, рекомендую `--page-art` из маленькой обложки и blur 32 | анимаций нет |
Общее: декор только на псевдоэлементах `.ps-app` (`pointer-events: none`, z-index −1/−2), анимируется только `transform`, в `@media print` скрыть.
PS1 (светлая) самая рискованная по объёму работы: компоненты с жёстко тёмными цветами (скелеты, скроллбары, `text-white` вне обложек), статусы перестают быть общими для всех тем (контракт `tokens.css` меняется: `--st-*`, `--success/warning/danger`, `--rar-*`, трофейные цвета, `--on-cover-*` становятся токенами темы). `contrast.test.ts` нужно читать статусы из каждой темы, а не из базы.

## 6. Что выбрать Артёму
1. Какие из PS1–PS5 оставить (можно все 5).
2. PS1: светлая (как в макете) или тёмный серый вариант (дешевле, без переопределения статусов). Если светлая: «спокойные» фигуры или «цвета кнопок».
3. Activity сливаем в PS5: да/нет.
4. PS3: фиксированный бордовый XMB или цвет фона по текущему месяцу, как в настоящем XMB (+1 токен `--xmb-hue`, frontend ставит месяц).
