# Фаза 29. Сводка в Telegram: тексты

Только тексты и правила сборки. Токенов и CSS нет, кроме блока E (настройки сайта: переиспользуем `.ps-panel`, `.ps-btn`, `.ps-btn--ghost`, `.ps-link`, `Icon`, §4 design-system).

## 0. Формат (по `src/server/notify/telegram.ts`)
| Что | Правило |
|---|---|
| parse_mode | Не задан: `sendMessage` шлёт `{chat_id, text, disable_web_page_preview:true}`. Это plain text. Экранирования нет и не нужно; Markdown/HTML-символов (`*`, `_`, `<`, `` ` ``) для разметки не используем. Не добавлять parse_mode в сводку и в ответы бота |
| Ссылки | Голый URL на отдельной строке, Telegram делает его кликабельным сам; превью отключено. Строит `gameLink(id)` / `gameLine(title,id)` = `{APP_ORIGIN}/?game=<id>`. Нет `APP_ORIGIN` или `id` -> строка без ссылки (так уже работает) |
| Эмодзи | Нет. Фигуры △○□✕ в тексте не используем (только статусы на сайте). Заголовки блоков словами |
| Разделитель блоков | Одна пустая строка. Заголовок блока отдельной строкой без двоеточия, дальше 1-3 строки |
| Префикс | Первая строка всегда «PS Tracker: итоги недели, {дд мес}–{дд мес}» (МСК, пн–вс, месяц сокр.: янв, фев, мар, апр, мая, июн, июл, авг, сен, окт, ноя, дек; если месяц один: «20–26 окт») |
| Длина | Цель до ~1500 символов, жёсткий предел 3500 (Telegram 4096). Усечение по порядку: сперва ссылки на игры блока «Трофеи» сверх 3, затем список «На следующую неделю» сверх 3, затем строка совета (причина обрезается до 160 символов с «…»). Блоки не режем посередине |
| Время | Воскресенье 19:00–21:00 МСК (время запуска задаёт backend); неделя = пн 00:00 – вс 23:59 МСК, текущая |
| Числа | Часы «12 ч 30 м» (как в чипе `inbox-hours`), без секунд; <1 ч «40 м»; 0 -> «0 ч». Склонения: игра/игры/игр, трофей/трофея/трофеев, платина/платины/платин, подсказка/подсказки/подсказок |
| Тон | На «ты», без восклицаний и оценок, как весь интерфейс |

## 1. Блоки сводки (порядок строго такой)
Пустой блок пропускается целиком, вместе с заголовком.

| # | Заголовок | Условие показа | Текст |
|---|---|---|---|
| 1 | `Часы` | `weekSeconds > 0` или `prevWeekSeconds > 0` | см. 1.1 |
| 2 | `Трофеи` | трофеев за неделю > 0 | «+{N} трофеев, платин: {P}.» (часть «, платин: P» только при P>0). Дальше до 3 строк платин: «Платина: {Название}» + ссылка на следующей строке. Платин нет: ссылок нет |
| 3 | `План` | у пользователя есть активный План (Фаза 12) | см. 1.2 |
| 4 | `Совет` | есть кандидат из «Подскажи» (Фаза 13), берём топ-1, не показанный в прошлой сводке | «{Название}» + строка причины (из LLM или шаблона, до 160 символов) + ссылка |
| 5 | `Статусы` | `checkCount + unsortedCount > 0` | «Подсказок по статусам: {N}. Разобрать: {origin}/triage?mode=check» (N = `checkCount` из `/api/inbox`; ссылка без `?game`, исключение из правила `/?game=<id>`: это не игра) |
| 6 | (нет, хвост) | всегда, если сводка не «пустая» | «Открыть: {origin}/» одной строкой, без заголовка. Нет `APP_ORIGIN` -> строки нет |

### 1.1 Часы
| Случай | Строка |
|---|---|
| Есть оба значения, разница ≥ 15 мин | «Сыграно {X} за неделю, на {D} больше прошлой.» / «…меньше прошлой.» |
| Разница < 15 мин | «Сыграно {X} за неделю, как на прошлой.» |
| `prevWeekSeconds = null` (нет снимков за прошлую неделю) | «Сыграно {X} за неделю. Для сравнения нет данных: история часов начинается с первого синка.» (вторая фраза только если истории нет вообще; если нет только за прошлую неделю: «Для сравнения нет данных за прошлую неделю.») |
| `weekSeconds = 0`, prev > 0 | «За неделю часов нет, на прошлой было {Y}.» |
| Оба 0 или нет данных | блок пропускается |
Дельта всегда словом «больше/меньше», знаков +/− в предложении нет.

### 1.2 План (Фаза 12)
Состояние берём то же, что на вкладке «План» («отстаю» = есть игры, пропустившие запланированный срок; «опережаю» = игр завершено/сыграно больше, чем по графику; иначе «по графику»).
| Что | Текст |
|---|---|
| Отстаю | «Отстаёшь: {N} игр от графика.» (склонение: «1 игра», «2 игры», «5 игр») |
| Опережаю | «Опережаешь: {N} игр.» |
| По графику | «Идёшь по графику.» |
| На следующую неделю | Строка «На следующую неделю:» и до 3 строк «- {Название}, {срок «пн–ср»}» + ссылка `?game=<id>` на следующей строке. Если игр на неделе нет: «На следующую неделю игр в Плане нет.» |
| План пуст/не создан | весь блок пропускается |

## 2. Короткий вариант (пустая неделя)
Условие: ни одного из блоков 1, 2 нет, и План, совет, статусы тоже пусты; либо только блок 5 без остального.
- Полная пустота: одна строка текста «PS Tracker: за неделю {дд}–{дд мес} игр и трофеев не было. Хорошей недели.» + строка «Открыть: {origin}/» (если есть origin). Заголовков нет.
- Пусты 1–2, но есть 3, 4 или 5: обычная сводка без пустых блоков, а первая строка после префикса: «За неделю игр и трофеев не было.»
- Пустую неделю всё равно шлём (воскресный ритм); отключается только отпиской (блок 3).

## 3. Привязка чата участника (бот)
Бот отвечает plain text. Код из настроек сайта, формат: 8 символов `A–Z0–9` без `0/O/1/I` (пример `K7M2QX9H`), жизнь 15 минут, одноразовый. Владелец привязан через `TELEGRAM_CHAT_ID`, `/start` ему не нужен (если пишет `/start` без кода: ответ как в 3.2).

| Команда / событие | Ответ бота |
|---|---|
| `/start <код>`, код верный | «Готово: чат привязан к {ник PSN}. Сводка будет приходить по воскресеньям вечером (МСК). Отписаться: /stop. Статус и настройки: {origin}/» |
| `/start <код>`, чат уже привязан к тому же пользователю | «Этот чат уже привязан к {ник PSN}. Отписаться: /stop.» |
| `/start <код>`, чат привязан к другому пользователю | «Этот чат уже привязан к другому аккаунту PS Tracker. Сначала отпишись там: /stop.» |
| Код неверный (нет такого) | «Код не подходит. Проверь, что скопировал его целиком, или создай новый в настройках сайта.» |
| Код просрочен или уже использован | «Код устарел или уже использован. Создай новый в настройках сайта: кнопка «Привязать Telegram».» |
| `/start` без кода | «Это бот PS Tracker. Чтобы получать воскресную сводку, открой настройки сайта, нажми «Привязать Telegram» и пришли сюда команду из подсказки: /start КОД.» |
| `/stop` (привязан) | «Отписал. Сводка больше не придёт, привязка удалена. Вернуться можно в настройках сайта.» |
| `/stop` (не привязан) | «Этот чат ни к чему не привязан.» |
| Любой другой текст | «Понимаю только /start КОД и /stop.» |
| Превышен лимит попыток кода (5 неверных за 10 мин на чат, решение backend) | «Слишком много попыток. Подожди 10 минут и создай новый код в настройках сайта.» |

Подтверждение на сайте (после привязки, тост/статус): «Telegram привязан.»

## 4. Исключения ссылок
- Игровые ссылки только `{origin}/?game=<id>`, строит `gameLink`; без id или origin не выводим.
- Служебные (`/`, `/triage?mode=check`) допустимы только при заданном `APP_ORIGIN`; без него строка и ссылка опускаются.
- Фраза «открой настройки сайта» без ссылки (origin может отсутствовать) в ответах бота остаётся в любом случае.

## 5. Настройки сайта: «Сводка в Telegram» (RU)
Компонент: `.ps-panel` в настройках, заголовок h3 16/22 600 «Сводка в Telegram», пояснение `--text-2` 14/20. Один блок на пользователя (у владельца тоже: его чат из env, отдельный статус).

| Состояние | Статус (иконка + текст) | Подпись | Действия |
|---|---|---|---|
| Не подключено | `bell-off`, «Не подключено» | «Раз в неделю, в воскресенье вечером (МСК): часы, трофеи, План и один совет. Присылает бот в Telegram.» | primary «Привязать Telegram» |
| Код создан | `clock`, «Ждём подтверждения» | «Пришли боту команду: /start {КОД}. Код действует 15 минут.» Код в `--font-mono` 20/28 с кнопкой «Копировать» (ghost, после нажатия «Скопировано» 2 с). Если задан ник бота: ссылка «Открыть бота» (`.ps-link`) | ghost «Новый код», ghost «Отмена» |
| Код истёк | `alert`, «Код истёк» | «Создай новый код и пришли его боту.» | primary «Новый код» |
| Подключено | `check-circle`, «Подключено» | «Сводка приходит в этот чат по воскресеньям вечером. Последняя: {дд мес, чч:мм} МСК» или «Ещё не отправлялась» | ghost «Отключить» (подтверждение: «Отключить сводку? Привязку чата можно создать заново.» кнопки «Отключить» danger / «Отмена») |
| Подключено у владельца | то же, подпись «Чат задан на сервере вместе с алертами.» | | «Отключить» нет (отключается через env), вместо него ничего |
| Бот не настроен (нет `TELEGRAM_BOT_TOKEN`) | `info`, «Недоступно» | «Бот Telegram на сервере не настроен.» | действий нет |
| Ошибка создания кода | `alert` | «Не получилось создать код. Попробуй ещё раз.» | ghost «Повторить» |
| Загрузка | `.ps-skeleton` вместо статуса и подписи (строки 16 и 40) | | кнопки disabled |
- Статус всегда текстом и иконкой, цвет только усиливает: `--success` подключено, `--warning` истёк, `--text-2` остальное.
- Мобильная (<768): панель на всю ширину, кнопки на всю ширину друг под другом (высота `--control-h`, 44 на touch), код переносится не должен: 20 px mono = 8 символов помещаются.
- `aria-live="polite"` на строке статуса; кнопки с `aria-label` равным видимому тексту.

## 7. Для теста (QA / backend)
- Фикстурные тесты 6.1–6.3 сравнивают текст построчно; длина 6.1 < 1500.
- Склонения: 1/2/5/11/21 для игра, трофей, платина, подсказка.
- Без origin: ни одной ссылки, остальной текст прежний.
- Ограничение 3500: 20 платин + 10 игр Плана не превышают предела, усечение по п. 0.
