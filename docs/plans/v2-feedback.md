## Context
Артём прислал замечания после первых фаз (Статистика, Коллекция, Бэклог) и 4 новые фичи. Фаза 7 (релиз) ещё открыта: миграция `0001` на Neon и прод-деплой. Цель: сначала исправить баги и быструю ценность, потом большие фичи с внешними сервисами (Haiku, HowLongToBeat).

- Сброс статусов: все 3 варианта (одна игра, по выделению, вся коллекция).
- Разрешены Haiku API, HowLongToBeat, ручной ввод часов.
- Темы: 5 новых PS1–PS5.

Порядок работы как раньше: контракт в `docs/` → backend/designer параллельно → frontend → QA-приёмка фазы.

## Фаза 8. Баги и быстрые правки (S)
**8.1 Баг оценки часов** (`src/server/stats/estimate-query.ts`)
- Конец оценки берётся из `games.last_played_at`, который синк перезаписывает. Должен браться `playtime_snapshots.last_played_at` первого снимка.
- Последствие: часы игры размазываются до октября 2026, декабрь получает около 1/11 часов.
- Плюс юнит-тест на кейс «первый запуск в декабре, игра в январе, игра после синка».

**8.2 «Сыграно в месяце» вместо «Пройдено и брошено»** (`src/server/stats/finished.ts`, `StatsView.tsx`)
- Месяцы игры: до первого снимка это диапазон оценки `[first_played_at .. last_played_at из снимка]`, после — месяцы, где по снимкам дельта > 0.
- Игра попадает в каждый такой месяц. Фигура статуса остаётся, если игру в этом месяце завершили или бросили.
- Блок переименовать в «Игры месяца»: счётчики ○/✕ и строка часов игры за месяц.
- Контракт §10 в `docs/api-contract.md` обновить первым.

**8.3 Сброс статуса**
- В окне игры: кнопка «Сбросить статус» (`PUT status {status:null}` уже есть).
- В режиме «Выбрать»: явная кнопка «Сбросить» (через `status-bulk`).
- Вся коллекция: новый `POST /api/games/status-reset-all` с подтверждением и откатом из снимка в ответе.
- Риск: сброс всей коллекции стирает ручные даты `completed_at`. Перед сбросом сохраняем копию в `status_backups`, откат по кнопке в toast.

**8.4 «По последней игре» с разбиением по годам** (`CollectionView.tsx`, `chronicle.ts`)
- Группировка по году `last_played_at` (МСК). Переиспользовать заголовки года из `Chronicle`.

**8.5 Удаление из коллекции**
- Мягкое удаление: `games.hidden_at` (миграция без потери данных). Синк не возвращает скрытые игры в выдачу.
- Без флага игра вернётся при следующем синке. Плюс раздел «Скрытые» в настройках для восстановления.

## Фаза 11. Бэклог: фильтры и время прохождения (M)
- `games.hltb_main_hours`, `hltb_extra_hours`, `hltb_id`, `hltb_checked_at`, `duration_override_hours` (ручная правка приоритетнее).
- Модуль `src/server/hltb/`: поиск по названию, кэш в БД, отдельная фаза синка батчами (раз в 30 дней на игру).
- Фильтры бэклога: жанры, длительность (до 10 / 10–30 / 30–60 / 60+ ч), сортировка по длительности.
- Риск: у HLTB нет официального API, парсинг ломается. Митигация: ошибка не роняет синк, ручной ввод, статус «не найдено».

## Фаза 12. Роадмап бэклога (L)
- Ввод: год, часов в неделю, список «пройти на релизе» (игра + дата релиза), игры из бэклога.
- Игр «на релизе» нет в PSN-библиотеке до покупки. Таблица `planned_games` (название, дата релиза, часы из HLTB/вручную, обложка по ссылке или из PSN-стора — проверить в psn-api).
- Алгоритм `src/server/roadmap/`: недели года с бюджетом часов. Релизные игры жёстко ставятся с даты релиза, бэклог заполняет промежутки по приоритету (ручной порядок drag&drop).
- Экран: таймлайн по месяцам, «отстаю / иду по плану» по факту часов из снимков, пересчёт после синка.
- Риск: даты релизов меняются, их правит Артём вручную. Haiku для дат не используем: ошибается.

## Фаза 13. Рекомендации (L, Haiku)
- Сценарии: «похоже на то, во что играю», «по любимым жанрам», «эксклюзивы PS, которых нет в коллекции».
- Вход для модели: топ игр по часам, статусы, брошенные (антипредпочтения), жанры, вся коллекция (чтобы не советовать имеющееся). Выход: JSON (название, причина, жанры, эксклюзив да/нет).
- `src/server/reco/`, модель Haiku последней версии, кэш ответа на сутки, лимит запросов. Ключ `ANTHROPIC_API_KEY` только на сервере.
- Кнопки: «В бэклог-план» (в `planned_games`), «Не интересно» (в контекст следующего запроса).
- Риски: модель может выдумать игру или ошибиться с эксклюзивностью. Помечаем «по данным модели», без ручной проверки. Платный сервис: нужно твоё согласие на ключ (оно есть), бюджет < $1/мес.
