## Что проверено

- **Топ по часам**: порядок (секунды, `lower(title)`, id), игры с 0 секунд не входят, пустой период даёт `{byHours: [], byTrophies: []}` и тексты «Нет данных за период» / «В этом периоде трофеев не получено». Скрытые игры исключены из топа и из `genres.games` (тест с `hidden`). Оценочные часы: `estimated = true` и «≈» в UI, `title` «Часть часов оценена». Топ берёт те же `h.seconds`, что и `hours`, поэтому сумма не расходится с блоком часов.
- **Топ по трофеям**: очки 15/30/90/300, период по `earned_at` (границы по МСК через `fromUtc/toUtc`), трофеи без даты не считаются, сироты и сеты скрытых игр отпадают на inner join, сет нескольких игр идёт игре с минимальным видимым id. Один сгруппированный запрос, карточки топа грузятся общим `getGamesByIds` (без N+1).
- **Жанры**: `gameIds` до 50, словарь `games` только по попавшим id, игра в нескольких жанрах присутствует в каждом, жанр без игр: строка без поповера, жанр с 0 ч: только число игр.
- **Поповер (десктоп)**: hover с задержкой, переход курсора в панель, focus-visible открывает сразу, Tab по миниатюрам, Esc закрывает и возвращает фокус на строку, «тихий» режим после возврата из окна игры (повторно не открывается). Открытие окна игры из поповера по stub, при 404 «Игра не найдена».
- **Поповер (touch)**: при `(hover: none)` и мобильном bottom sheet по тапу, сетка 4 колонки, цель касания >= 44 px, без переполнения.
- **Три темы**: поповер и топ без переполнения на desktop и mobile (e2e), скриншоты просмотрены.
- **Вес ответа**: добавка ограничена (до 20 `GameItem` в `top`, до 8 x 50 коротких записей в `genres.games`). BUG-P8-3 не ухудшен.

## Баги

### BUG-P10-1. Плейсхолдер обложки в миниатюре топа ломает вёрстку (низкая, frontend) [ИСПРАВЛЕНО: инициал вместо названия]
Шаги: `/stats` с играми без `coverUrl` (например, заглушка).
Факт: в миниатюре 32x40 название рисуется столбиком по буквам («И Г Р А»), текст обрезан сверху и снизу (скриншот `p10-top-night-desktop.png`). Для `Cover` без картинки в мелком размере нужно показывать инициал или иконку, а не название. Реальные игры почти всегда с обложкой, поэтому низкая.

### BUG-P10-2. Тай-брейк названий считается по-разному в JS и SQL (низкая, backend) [ИСПРАВЛЕНО: сравнение кодовыми точками, тест на ничью]
`byTitle` в `src/server/stats/top.ts` использует `toLowerCase().localeCompare()` (локаль среды), контракт 13.1/13.2 говорит `lower(title)`. На Vercel и в тестах порядок кириллицы и латиницы при равных очках или секундах может не совпасть с ожидаемым. Серьёзность низкая: влияет только на порядок ничьих. Предложение: сравнивать кодовыми точками (`<`/`>`) либо зафиксировать `localeCompare('ru')`.
