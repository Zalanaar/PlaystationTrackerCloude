## Что проверено

Расчёты (PGlite, `src/server/wrapped/query-sql.test.ts`, 30 игр, ~7 тыс. снимков, 40 платин, годы 2025..2027):
- Топ-5 по часам года против SQL (секунды и порядок), ничья: `lower(title)` затем `id` (Alpha/alpha/beta). Более 5 игр с равными часами: ровно 5, ранги 1..5.
- Самая долгая = №1 топа, `playCount` общий.
- Пройдено/брошено: счётчики, «больше всего в месяце» по МСК (ничья = ранний месяц), граница 21:00Z 31 дек = 1 янв.

- Жанры топ-3 с весом 1/N, SIMULATOR/UNIQUE, override, игры из часов и из пройдено/брошено.
- `mode`/`slides`: нет часов, но есть трофеи = `start, trophies, final`; пустой, будущий, 2000 и 2100 = `empty`; `hours.total` и `byMonth` равны `getStats` за тот же год.
- `years[].hasData` против реального `mode` по годам (пусто, только трофей, только статус, только часы, всё): совпало.

UI (`e2e/wrapped.spec.ts` разработчика перепроверен, плюс `e2e/wrapped-qa.spec.ts`):
- Сегментов столько же, сколько слайдов; неизвестные и повторные id отбрасываются.
- Тап (граница 30%), свайп (вертикальный игнорируется), удержание не листает при отпускании, последний слайд не закрывается сам и по тапу/стрелке, Пробел на кнопке финала не листает, Esc с любого слайда, фокус возвращается на кнопку, scroll страницы разблокируется, focus trap, reduced-motion (нет автоперехода, счётчик сразу).

- 503 при первой загрузке и при смене года, «Повторить» восстанавливает выбранный год.
- Стресс-мок: названия 80+ символов без пробелов и с пробелами, 7 жанров, 12 карточек годов, числа вида 1 234 567: на 1280x800, 390x844, 360x640 вылезаний нет, горизонтального скролла нет.

## Риски

- Десктоп с высотой окна менее 640px (ноутбук 1280x600, окно браузера с панелями): сцена имеет `min-height: 640` по спеке, верх и низ обрезаются (скругления, прогресс почти у кромки), ✕ остаётся видим. Работает, но выглядит обрезанным.
- Клавиши, нажатые в первый тик после открытия (до монтирования портала `setTimeout 0`), теряются. На практике незаметно.
- `getWrappedYears` делает `lag` по всем снимкам БД на каждый запрос `/api/wrapped`, плюс загрузка всех игр для жанров. Без кэша, на Neon HTTP замера нет (как в риске Фазы 5).
- Платины `first`/`last` в UI не показываются (только «самая редкая», и только если есть `game`: платина сета-сироты в слайде не отображается). Не противоречит §4.12, но данные контракта используются частично.
- Слайд «Самая редкая платина» показывает название игры, а не платины (`name` может быть `null`), допустимо.

## Не проверено

- Реальная БД Neon и реальные данные Артёма (только PGlite и моки). Сам HTTP `GET /api/wrapped` с сессией не перепроверялся (есть `route.test.ts` разработчика).
- Реальные обложки: во всех тестах `coverUrl = null` (плейсхолдер с названием), размытый фон из обложки по §4.12 не оценён визуально.
- Тач-устройства физически: свайп и удержание проверены только эмуляцией мыши/pointer; iOS Safari (`100dvh`, safe-area) не проверялся.
- Остальные 4 темы не снимались (в проекте три).
- Счётчик 0 -> значение за 900 мс проверен только по итоговому значению, не по анимации.
