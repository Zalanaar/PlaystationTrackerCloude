## Флак `reduced-motion`
Причина в тесте, не в продукте. При нагрузке (`--workers 4`, 15 повторов) падал 15 из 30 с `animationName === ''`: `getComputedStyle` берётся у узла, который уже отсоединён (скелет подменяется при гидратации), у отсоединённого элемента значение пустое. CSS (`.ps-skeleton { animation: none }` в `prefers-reduced-motion`) верный. Поправил `e2e/phase18.spec.ts`: ждём устойчивого значения свежим запросом по подключённым узлам. После правки 30/30 при тех же условиях.
