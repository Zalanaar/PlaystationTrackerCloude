## Замечания без номера
- Страница `/offline` динамическая (`ƒ` в сборке), в HTML есть inline-скрипты с nonce (тема, поток Next), хотя комментарий в `page.tsx` говорит «без inline-скриптов». Работает, т.к. кэшируется ответ вместе с CSP-заголовком; комментарий неточен.
- `/offline` и статика перекэшируются только при смене байтов `sw.js` (нужно менять `VERSION` при каждой правке, иначе заглушка со старыми чанками живёт до следующей версии SW). Риск процесса, не дефект.
- Подсказка на Android в обычном Chrome без `beforeinstallprompt` не показывается (по спеке).

## Не удалось проверить
- Lighthouse PWA (не установлен, сети для установки нет); installability проверена по критериям вручную.
- Реальные Android Chrome и iOS Safari: системный диалог установки, вырез и home-indicator, standalone на iPhone (оттяжка, статус-бар), safe-area на устройстве. Standalone эмулирован подменой `navigator.standalone` и `matchMedia`, так как CDP-эмуляция `display-mode` в Chromium не действует.
- Подсказка при открытом окне игры и во время тура (нужна БД с играми и тур); `[role="menu"]` как признак оверлея не проверялся.
- Конфликт с `.ps-wn`, `.ps-toasts`, `.ps-selbar` (нужны данные).
- Скриншоты тем сняты на экранах с состоянием ошибки (БД недоступна); сверка с реальной коллекцией не делалась.
