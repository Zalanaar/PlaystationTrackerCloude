Критерии плана:
1. База пройдена, DLC нет: `platinum-dlc.test.ts` (PGlite) даёт progress 100, remaining 0, `dlc` отдельно, approximate=false. «Подскажи»: `db.test.ts` даёт полный `platinum_close` (1.5) при 8/8 базы и 2 невыполненных DLC. Прогноз в окне игры и «Ближе к платине» делят один расчёт (`platinum.ts`, `platinum-query.ts`).
2. Добор `group_id`: `trophiesPhase` берёт сеты с `group_id IS NULL` (не чаще раза в сутки на сет, по одному сету за итерацию, `outOfTime` -> `timeout`, возобновление через повторный запрос «устаревших»). Определения запрашиваются только для таких сетов. Тест `stage2.test.ts`: одна перезагрузка определений на один сет с NULL, повтор ничего не меняет, число строк не растёт. Принято.
3. Изоляция `user_id`: новый запрос в `recommend/db.ts` фильтрует `gameTrophySets.userId` и `trophies.userId`; тест с двумя пользователями и одинаковым `npCommunicationId` зелёный. `platinum-query.ts` не менялся, фильтры есть. Утечек нет.
4. «≈» только при `approximate === true` (`FORECAST_APPROX` удалён, undefined -> без «≈»); e2e проверяет оба случая.
5. «Подскажи»: порядок выдачи не меняется, кроме игр с DLC (они выросли). В UI и тексте ответа «DLC-хвост» не выводится (`dlcTail` всегда false в `db.ts`).
6. 320 и 412 px: нет горизонтального скролла, текст DLC не обрезается, высота карточки >= 112. 7 тем: проверен только ненулевой цвет `.ps-near__dlc`.

## Замечания
- **QA-36-1 (низкая).** Мёртвый код `dlcTail`: ветка штрафа x0.5 в `src/server/recommend/score.ts:83-86`, подпись «есть DLC-хвост» в `score.ts:143`, тесты `scoring-edge.test.ts:49,139`, `score.test.ts:116`. Пользователю текст недоступен (флаг всегда false), но тесты закрепляют отключённое поведение, следующий читатель решит, что штраф работает. Предложение: удалить поле и ветки отдельным заходом.
- **QA-36-2 (низкая, край).** DLC-группа только из платинных трофеев. В `platinum-query.ts` и `isDlcTrophy` (UI) платина в DLC не учитывается: `dlc=null`, бейджей «DLC» нет, строка DLC не показывается; платина считается по сету целиком. Это согласовано с контрактом 15.3 (платины в DLC не бывает). Но `recommend/db.ts` вычитает из сумм все трофеи с `group_id` не `default`, включая платину: для такого гипотетического сета «Подскажи» занизит `total` на платину, а прогноз платины нет. На реальных данных PSN не воспроизводится. Рекомендую добавить `type <> 'platinum'` в условие вычитания для единообразия.
- **QA-36-3 (информационная).** Название фазы в `plan.md` ещё говорит «миграция `0026`», «`trophyGroupId` у трофеев (синк)»; по факту миграции нет. При закрытии фазы поправить заголовок. Пока сеты с `group_id IS NULL` не дозагружены, «Подскажи» и прогноз остаются приблизительными (ожидаемо, описано в контракте).
