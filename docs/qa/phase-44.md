## Проверка по заданию

1. **Изоляция.** Все запросы `other-platform.ts` и `store.ts` идут с `eq(m.userId, userId)`; user берётся из `requireUser`, активный профиль. `removeManual` тоже по `userId`+`id`. Уникальность `(user_id, rawg_id, kind)` в БД. Тесты на изоляцию (другой вход и другой профиль того же входа) есть и зелёные. Запросов без фильтра по пользователю нет.
2. **Нулевое влияние.** `manual_games` читают только: `manual/store.ts` (Бэклог: везде `kind='ps_backlog'`; список, счётчик, «Не куплено», `setNotPurchased`, `manualExists`, склейка, `addManual`), `sync/manual-match-step.ts` (`ps_backlog`), `owned/marks.ts`. Статистика, Итоги, Коллекция, План, прогнозы, «Подскажи» таблицу не читают; тест `нулевое влияние на Статистику, Итоги, Бэклог, План, прогнозы, «Подскажи»` зелёный. Единственное влияние, как и задумано: `rawg_id` исключается из «У тебя нет» и поиска в План (`manualRawgIds`/`ownedRawgIds` берут любой kind). Вкус профиля не затронут.
3. **Фаза 43/43.1.** `listManual`, пакет, suggest, `answerMatch`, `loadDupIndex` фильтруют по kind (`linkedByRawg`/`backlogRawg` только ps_backlog). Одна игра может быть в обоих списках (тест). Регрессий нет: unit и e2e 43/43.1 зелёные.
4. **Валидация.** Строгая схема; `platformLabel` 1..60, запрещены управляющие символы и `<` `>`, `notPurchased` у other_platform = 400, CHECK в БД дублирует. React экранирует вывод, XSS нет. `coverUrl` только `https://`. Лимит 300 = 409 `manual_limit` с `details.limit`; повтор существующей записи при полном списке не падает. Идемпотентность по `(user, rawg, kind)` и при гонке (`onConflictDoNothing` + перечитывание). «Вернуть» после удаления = повторный POST, в дубле с `confirmDuplicate`; покрыто тестом и e2e. Дубль с библиотекой/Планом = 409 `duplicate_game`, 503 без текста исключения.
5. **UI.** e2e: 7 тем без горизонтального скролла, 320/360/390/412, тап-зоны >= 44, reduced-motion, Esc и фокус-ловушка, фокус после добавления и удаления, состояния (загрузка, пусто, ошибка, офлайн, квота, каталог, manual_limit). В CSS новых hex/rgb нет (`manual.css`). `src/ui` не импортирует рантайм из `src/server`: только `import type`/`export type`.
6. Ручной визуальный просмотр снимков в этой приёмке не делался: вёрстку подтверждают e2e-проверки (скролл, тап-зоны, темы).
7. **Отступление frontend (нет статуса игры в блоке дубля).** QA-44-1, Low: спека критична только к самому блоку и «Всё равно добавить»; статус не влияет на решение (запись other_platform статуса не имеет). Принимается.
