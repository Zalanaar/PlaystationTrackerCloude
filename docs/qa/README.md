# docs/qa

Отчёты QA по фазам и пакетам (`phase-*.md`, `tails-*.md`, `stage-*.md`) и таблица переименования тестов (`test-renames.md`).

## Скриншоты (с 2026-11-03)

- PNG/JPG/WebP в `docs/qa/` в git **не хранятся** (`.gitignore`: `docs/qa/**/*.png` и др.). Уже закоммиченные ~69 МБ (510 файлов) сняты с учёта через `git rm --cached` без переписывания истории: в истории они остаются, прочитать старый снимок можно так: `git show d56f1fe:docs/qa/shots-41/<файл>.png > /tmp/x.png` (d56f1fe — последний коммит, где они есть в дереве).
- e2e-спеки со снимками пишут в `test-results/shots/<папка>` (хелпер `e2e/shots.ts`) или в `SHOTS_DIR`, если он задан. `test-results/` в `.gitignore`, в CI это артефакт `playwright-test-results` (загружается при падении).
- В отчёте QA описывайте, что видно на снимке, и где его взять (артефакт CI, команда запуска), а не коммитьте PNG. Эталоны дизайна (`docs/reference/*.png`) и иконки приложения (`public/icons`, `src/app/apple-icon.png`) — исключение, они нужны в репозитории.
