Источники значений: `src/ui/tokens/` (`tokens.css` базовые, `themes.css` значения тем, `decor.css` декор тем, `index.ts` константы, `tailwind.tokens.ts` маппинг в Tailwind, `contrast.test.ts` проверка контраста).
Макеты (утверждены Артёмом): `docs/design/mockups/*.html`, обоснование: `docs/design/proposal.md`. Если спека и макет расходятся, прав этот документ.
Спека экрана «План» (Фаза 12, `/roadmap`): `docs/design/spec-phase-12-roadmap.md` (вкладка в NAV и tab bar, иконка `roadmap`, токены `--rm-*`; при расхождении по этому экрану прав она).
Спека экрана «Подскажи» (Фаза 13, `/recommend`): `docs/design/spec-phase-13-recommend.md` (вкладка в NAV и tab bar, иконки `lightbulb` и `thumbs-down`, новых токенов нет; при расхождении по этому экрану прав она).
Фаза 18 (UX): раздел «8. Фаза 18» в конце документа (навигация из 4 вкладок, длинные страницы, мобильный первый экран, error/not-found/скелетоны, иконка и manifest, ссылка `/?game=`). Где §4.1, §4.3, §4.11, §5 расходятся с §8, прав §8.

### 1.2 Типографика
Шрифты (next/font, subsets `latin`+`cyrillic`, `display: swap`): Inter (400/500/600/700) в `--f-inter`, Unbounded (500/600/700) в `--f-unbounded`. Одинаковы во всех темах (бренд, не тема).
| Токен | Значение |
|---|---|
| `--font-body`, `--font-num` | Inter (`tabular-nums` для чисел) |
| `--font-display` | Unbounded |
Display-шрифт только для: логотип, h1, `h2` блоков, год в хронике, крупные числа, название в Разборе, числа Итогов. Названия игр и весь остальной текст Inter. Заголовки Unbounded с `letter-spacing: -.01..-.02em`.

Формат времени везде: «17 ч 51 м», меньше часа «45 м», от 100 ч без минут «128 ч», ноль не показывается. Числа от 10 000 в формате `12 345`. ## 2. Темы (семь)
Меню: Night, Graphite, PS1, PS2, PS3, PS4, PS5 (`THEMES` в `index.ts`; подписи «Night», «Graphite», «PS1»…«PS5»). Одна разметка: тема = значения токенов (`themes.css`) + декор (`decor.css`). Атрибут `data-theme` стоит на `<html>`, Night без атрибута. Тема PS5 это бывшая Activity (слита, §2.6).
Идеи: PS1 серый корпус (единственная светлая), PS2 синий экран Memory Card, PS3 XMB (бордовая волна, фон по месяцу), PS4 синие плитки, PS5 чёрный фон и белые pill с размытым артом игры.

## 6. Контраст и читаемость на обложках
Обложки произвольные (светлые, как ACE COMBAT, и тёмные): текст и фигуры не кладутся на обложку без подложки.
| Правило | Значение |
|---|---|
| Текст и фигуры поверх обложки | только внутри `--on-cover-bg` (`rgba(8,9,14,.78)`, blur 4): фигура статуса, платина, плашка даты. Белый текст на чипе поверх белой обложки около 10,7:1 (проверяется `contrast.test.ts`), добавлены `text-shadow: 0 1px 2px rgba(0,0,0,.6)` и обводка `--on-cover-border` |
| Hover-оверлей | белый текст на `--cover-scrim` (.88 → 0), высота зависит от текста, не менее 36 сверху |
| Название игры | не на обложке, а на `--bg` (под обложкой); плотный режим: в оверлее |
| Hero и арт окна | текст на арте только в нижних 55% hero (затемнение не слабее .6, белый текст на белом арте >= 5,5:1) + `text-shadow`; на мобильном текст вообще не на арте. Арт окна игры без текста. Размытая обложка `brightness(.7)` |

### 8.6 Ссылка на игру `/?game=<id>` (18.6)
`<id>` = `GameItem.id` как в API. Ссылка работает только на `/`; формат `/?game=<id>[&tab=trophies]` (остальные параметры Коллекции допустимы и применяются к фону).
| Ситуация | Поведение |
|---|---|
| Игра в уже загруженном списке | `GameDialog` (§4.15) открывается поверх Коллекции сразу, из `snapshot` |
| Игры нет в списке (грузится/на другой странице/скрытая) | диалог открывается сразу: арт-шапка скелет, заголовок скелет 200x24, плитки скелет; данные из `GET /api/games/{id}`. Коллекция под ним грузится параллельно |
| Игра найдена | диалог подставляет данные без перемигивания; скрытая игра показывается с плашкой «Убрана из коллекции» (§4.15) |
| `id` неверного формата или API 404 (в том числе игра чужого пользователя, Фаза 20) | диалог не открывается. Коллекция показывается как обычно, параметр `game` убирается через `replace`, тост (`--surface-3`, 4с) «Игра не найдена. Возможно, ссылка устарела.» |
| Ошибка сети или 5xx | диалог открыт, внутри панель ошибки §4.15 («Не удалось загрузить игру», «Повторить», «Закрыть»); параметр остаётся |
| Нет сессии | `/login?next=` сохраняет полный путь с query, после входа открывается тот же диалог |

| Правило | Спека |

| Открытие из приложения | клик по карточке, строке, миниатюре тоже ставит `?game=<id>` через `router.push` (`scroll: false`), чтобы системная кнопка «назад» (мобильный жест) закрывала диалог |

### 9.1 Когда отправлять на `/onboarding`
Решает серверный layout `(app)` по `GET /api/me/psn` (не `proxy.ts`, не клиент; API не редиректятся).
| Условие | Действие |
|---|---|
| сессия есть, `status = active`, и (`onlineId = null` или `onboardedAt = null`) | любая страница `(app)` -> `redirect('/onboarding')` |
| `onboardedAt != null` и `onlineId` задан | `/onboarding` -> `redirect('/')`. Даже если `accessStatus <> 'ok'` (приватный профиль позже): пользователь видит свои данные и баннер ошибки синка (§4.13) со ссылкой «Проверить доступ» на `/onboarding?recheck=1` (шаг 2 без редиректа) |

### 9.6 Мобильная версия и a11y
- <768: панель без `--shadow-pop`, отступ от шапки `--sp-4`; основные кнопки на всю ширину высотой `--tap-min`; две кнопки в столбик (primary сверху, ghost снизу); степпер остаётся (без подписей шагов, только «Шаг 1 из 3»). ### 10.7 Якоря `data-tour` (для frontend)
Один якорь = атрибут `data-tour="<id>"` на существующем элементе. Правила: (а) данные-зависимые якоря ставятся только когда элемент существует и не пуст (пустой бэклог: атрибута нет); (б) один id может быть на двух элементах (десктопный и мобильный), тур берёт первый видимый (rect > 0, не `display: none`, не `visibility: hidden`); (в) якорь не меняет вёрстку.
| id | Где | Условие |
|---|---|---|
| `nav` | `<nav class="ps-nav">` и `<nav class="ps-tabbar">` в `AppShell.tsx` | всегда |
| `game-card` | `<article class="ps-card">` первой карточки на `/` (первая в DOM-порядке среди всех блоков Коллекции, не в режиме выбора) | есть хотя бы одна игра |
| `card-status` | `.ps-card__status` той же карточки (десктоп; на мобильном статус через долгий тап, якорь `game-card`) | как выше |

| `filters` | `.ps-tabs` в `StatusChips` (чипы статусов + «Платина»; на десктопе в `ps-filters__row`) | не на мобильном (там `filters-btn`) |

### 11.3 Структура и поведение

### 12.3 «Длительность прохождения» свёрнута до строки

Секция `.ps-gd__duration` на «Обзоре» по умолчанию показывает одну строку высотой 44 (моб. 48): слева `h3`-подпись «Длительность прохождения» (micro uppercase `--text-3`, остаётся `h3` для a11y), справа значение `durationText` (14/20, 600, `num`) + бейдж источника `.ps-bl-src` и кнопка-шеврон `ps-btn--ghost` 32x32 (моб. 44) с `chevron-down`/`chevron-up`, `aria-expanded`, `aria-controls` = id тела, `aria-label` «Показать детали длительности» / «Скрыть детали длительности». Развёрнутое состояние = прежнее содержимое (HLTB, форма «Своя оценка»). Состояние раскрытия локальное, не хранится; при смене игры (`key={game.id}`) сбрасывается в «свёрнуто». Если во время сохранения (busy) блок свернули, запрос не отменяется. Ошибка сохранения раскрывает блок автоматически (чтобы её было видно). Стартовое раскрытие по `?edit` не используется.

### 12.4 Критерии приёмки

- [ ] Блок «История игры» есть на «Обзоре», когда есть недели; нет блока, когда `history: null` или `weeks: []`.
- [ ] Штриховые столбцы подписаны «оценка» в легенде; без `hasEstimate` штриховки и пункта легенды нет.
- [ ] Платина и трофеи видны на одной шкале с часами, у платины иконка, не цвет.
- [ ] Игра без снимков: нет столбцов, есть отметки трофеев и пояснение.
- [ ] «Длительность прохождения» свёрнута до строки, раскрывается и сворачивается с клавиатуры, значение видно в свёрнутом виде.
- [ ] 7 тем, мобильный 390: без горизонтального скролла, текст не обрезается.

## 12. Фаза 31: «У тебя нет» в «Подскажи»

Экран `/recommend` получает вторую вкладку «У тебя нет»: игры PS5/PS4 вне библиотеки по любимым жанрам (контракт «Фаза 30»). Новых токенов, цветов и иконок нет: всё на существующих (`--surface*`, `--border*`, `--text*`, `--accent`, `--r-*`, `--sp-*`, `--control-h`, `--tap-min`, `--card-gap`, `--dur-*`), иконки `plus`, `thumbs-down`, `external-link`, `check`, `info`, `circle-alert`, `clock`, `lightbulb`, `refresh`. 7 тем работают без правил темы: вкладка и карточка берут цвета из токенов, активная вкладка `--surface-3` (как `.ps-rec-seg`), у темы Memory Card (`data-theme="ps5"`) акцентная заливка, как у сегмента времени.

### 12.1 Вкладки режимов
- Полоса `.ps-seg.ps-rec-modes` под заголовком `Подскажи`, `role="tablist"`, `aria-label="Режим подсказок"`; две кнопки `role="tab"`: «Из бэклога» и «У тебя нет». - 7 тем: вкладки, карточка, панели состояний читаются, ничего хардкодом (проверить grep по `#`/`rgb(` в `recommend.css`).
- Десктоп 1280: 3 колонки, мобильная 360: 1 колонка без горизонтального скролла.
