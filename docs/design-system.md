# PS Tracker: дизайн-система

Источники значений: `src/ui/tokens/` (`tokens.css` базовые, `themes.css` значения тем, `decor.css` декор тем, `index.ts` константы, `tailwind.tokens.ts` маппинг в Tailwind).
Референсы: `docs/reference/collection-reference.png`, `docs/reference/themes-overview.png`.
Правило: в компонентах нет hex и px-цветов, только токены. Тема = `<html data-theme="...">`; Night = без атрибута. Выбор хранится в `localStorage['ps-theme']` и cookie (чтобы SSR не мигал), применяется inline-скриптом в `<head>`.

## 0. Отличия от референса коллекции
| Референс | В MVP |
|---|---|
| Вкладки План, Подскажи | Нет (вне MVP). Вкладки: Коллекция, Бэклог, Статистика, Итоги |
| Фильтры Xbox/Switch/PC | Нет. Только PSN |
| Переключатель светлая/системная/тёмная | Заменён селектом 7 тем |
| Кнопка «Импорт из PSN» | «Синк сейчас» |
| Кружок-логотип PlayStation на карточках | Текстовый бейдж `PS` (фигуры только для статусов) |
| Засечный шрифт | Это фолбэк референса; используем Inter/Manrope |

## 3. Статусы

Иконки: SVG 16x16, `stroke: currentColor`, `stroke-width: 1.75`, `fill: none`, `round` caps/joins. Пути в `STATUS_ICON_PATHS` (`index.ts`). Иконка всегда вместе с подписью (цвет не единственный признак).
| Статус | Иконка | Цвет | Подпись |
|---|---|---|---|
| `playing` | △ треугольник | `--st-playing` | Играю |
| `completed` | ○ круг | `--st-completed` | Пройдено |
| `backlog` | □ квадрат | `--st-backlog` | Бэклог |
| `dropped` | ✕ крест | `--st-dropped` | Брошено |
| `shelved` | ‖ пауза (две вертикальные черты) | `--st-shelved` | Отложено |
| без статуса | пунктирный круг (`stroke-dasharray: 2 2.5`) | `--st-none` | Без статуса |

Обоснование `shelved`: четыре фигуры PlayStation заняты, пятая фигура разрушила бы идею «фигуры только для статусов»; пауза это не кнопка геймпада, читается как «отложено, вернусь», силуэт (две черты) не путается с △○□✕ на 16px. Серо-лавандовый цвет «нейтральный», не конкурирует с активными статусами.

Компонент `StatusChip`: высота 24, padding 0 8, gap 4, радиус `--r-pill`, фон `color-mix(in srgb, var(--st-x) 16%, var(--surface-2))`, текст `--text`, иконка цвета статуса, текст small. Вариант «без статуса»: рамка dashed 1px `--border-strong`, фон прозрачный. Вариант `icon-only` 24x24 для узких мест (всегда `aria-label` и `title`).
Выбор статуса: `Menu` из 6 пунктов (5 + «Без статуса»), каждый: иконка 16 + подпись, строка 40px (моб. 48).

Логотип: текст `PS TRACKER`, display-шрифт темы, 14px, 800, uppercase, `letter-spacing .14em`, цвет `--text`. Без фигур.

## 6. Контраст и читаемость на обложках
Обложки произвольные (светлые, как ACE COMBAT, и тёмные), поэтому текст не кладётся на обложку без подложки.
| Правило | Значение |
|---|---|
| Текст поверх обложки | только внутри чипов с `--on-cover-bg` (`rgba(8,9,14,.78)`, blur 4) и белым текстом: на белой обложке фон чипа даёт примерно 6:1 (оценка), поэтому чипам добавлены `text-shadow: 0 1px 2px rgba(0,0,0,.6)` и 1px рамка `rgba(255,255,255,.12)`; цель не ниже 4.5:1, QA проверяет на светлой обложке (ACE COMBAT из референса) |
| Нижняя полоса трофеев | чипы на `--on-cover-bg`; если нужна подложка шире чипов, использовать `--cover-scrim` высотой 56px |
| Название игры | в карточке не на обложке, а на `--surface` (см. референс) |
| Попап/Играю сейчас | текст на `--surface-2` / `--surface`, не на обложке |
| Wrapped поверх обложки | размытая обложка + равномерная подложка `rgba(0,0,0,.55)` + градиент снизу `--cover-scrim`; текст белый, тяжёлый (>=600) при размере до 16px |
| Цвет текста | не бывает `--accent` поверх обложки |
| Акцент текстом на `--surface` | допустим (контраст акцента темы на её `--surface` не ниже 4.5:1), для мелкого текста <14px использовать `--text` |
| Статусные цвета как текст | допустимы только на `--bg`/`--surface`; на `--surface-2/3` и поверх чипов с заливкой текст `--text`, цвет несёт иконка |
| Плашка «Завершено» | текст #04231d на #3be8c8 (> 9:1) |
| Фокус | кольцо 2px `--focus` с зазором 2px `--bg` виден в каждой теме; не убирается |
| Цвет не единственный признак | статус всегда иконка + подпись/`aria-label` |
| Hover-подъём | не единственный признак интерактивности: курсор pointer + focus ring |
Размеры текста: минимум 11px только для micro/чипов, остальной текст от 12px.
